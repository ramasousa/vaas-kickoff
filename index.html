Contexto desta apresentação
O VaaS nasceu como uma tese de Full Commerce veicular. Nesta versão, focamos no ganho imediato de maior impacto — pagamento de tributos de forma conversacional dentro do próprio app Bradesco, sem redirecionar o cliente para outros canais.

Os materiais abaixo cobrem a demonstração interativa, o mapeamento completo de gaps para produção plena e a arquitetura AWS de referência — Multi-AZ, alta volumetria, Direct Connect e todos os aspectos de rede para o cenário bancário.

Arquitetura AWS · Produção

Alta Volumetria
Arquitetura de referência para produção com 500 TPS no pico de IPVA — Multi-AZ, VPC com 4 camadas de subnet, Redis Cluster Mode (9 nodes), ECS Auto Scaling 3→20, Direct Connect 1Gbps para o Axway.

ALB + WAF v2 + Route 53 · TLS 1.3 · 11 VPC Endpoints (PrivateLink)
Redis Cluster 3 shards × 3 nodes · DynamoDB On-Demand · Step Functions Express
Direct Connect 1Gbps + VPN failover · Transit Gateway · DR RPO <30min

Como usar na reunião
Demo (material 01) — comece pelo botão ▶ Play para rodar o fluxo automaticamente, ou use Próximo ▶ para avançar passo a passo. Alterne entre MVP e Produção para mostrar a diferença de escopo.

Gap Analysis (material 02) — use a seção Roadmap para posicionar o que está pronto vs. o que vem nas próximas fases. A seção Cobertura UFs é o argumento mais forte para justificar a expansão multi-estado.

Arquitetura AWS (material 03) — comece pelo Diagrama (visão física da VPC com subnets e AZs), depois vá para Compute & Scaling para mostrar as 4 políticas de Auto Scaling. A aba Custo tem os números de R$10.672/mês baseline vs. R$15.590/mês no pico de março.
